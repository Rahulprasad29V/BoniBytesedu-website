## 🎯 About the Project

**Boni Bytes Edutech** is a premium software agency that provides:

- 🌐 **Website Development** – Modern, responsive websites
- 📊 **CRM & ERP Solutions** – Custom business software
- 🤖 **AI Automation** – Intelligent chatbots and workflows
- 📱 **Mobile Applications** – Cross-platform native apps
- 🎓 **Edutech Services** – Internships and corporate training

This repository contains the complete source code for the company's official website.

## ✨ Features

### 🌙 Design & UI
- ✅ **Dark/Light Mode** – Smooth theme switching
- ✅ **Premium Animations** – Smooth transitions and effects
- ✅ **Responsive Design** – Mobile, tablet, and desktop optimized
- ✅ **Modern UI** – Glass-morphism, gradients, clean typography
- ✅ **Interactive Elements** – Hover effects, cursor glow

### 📄 Pages
- ✅ **Home** – Hero section with animated stats
- ✅ **Services** – 6+ service cards with details
- ✅ **Portfolio** – Project showcase
- ✅ **Testimonials** – Client reviews
- ✅ **Pricing** – 3-tier pricing plans
- ✅ **FAQ** – Accordion-style questions
- ✅ **Contact** – Working contact form
- ✅ **Blog** – Articles and updates
- ✅ **Internship** – Career opportunities
- ✅ **Admin Login** – Backend access

### 💬 Features
- ✅ **WhatsApp Integration** – Direct chat
- ✅ **Contact Form** – EmailJS powered
- ✅ **Social Media** – LinkedIn, Instagram, GitHub
- ✅ **Newsletter** – Subscribe for updates

### 📱 Additional
- ✅ **SEO Optimized** – Meta tags and structured data
- ✅ **Fast Loading** – Optimized assets
- ✅ **Accessibility** – ARIA labels and keyboard navigation
